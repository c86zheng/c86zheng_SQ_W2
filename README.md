# week 2 EX02

**Controls:**

- Move Left: A / Left Arrow
- Move Right: D / Right Arrow
- Jump: W / Up Arrow
- Debug Mouse Coordinates: K

Players control a sushi character to move, jump, and explore platforms placed throughout the scene. Some platforms are intentionally hidden or narrow, encouraging exploration and precise movement.

Press **K** during gameplay to output mouse coordinates into the browser console for debugging and level placement.

**Opening the Chrome Console**

- **Windows:** Press `F12` or `Ctrl + Shift + J`, then click the **Console** tab
- **Mac:** Press `Cmd + Option + J`

The console will show any errors in your sketch.
